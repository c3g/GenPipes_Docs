GenPipes 6.1.1 Release Notes
============================

What's new? 
-----------

This is a minor release of GenPipes: 

* General
     - Project Tracking Option: Starting with this release, MD5 checksums are now created in the JSON format for all generated output files.

* :ref:`LongRead DNASeq Pipeline <docs_gp_longread_dnaseq>`
    - The platform parameter used for `clairS` can now be set via the config file.
    - The issue of non-unique nanoplot metrics output file names is fixed.
* :ref:`RNASeq <docs_gp_rnaseq>`
     - The table containing differential expression results now includes column names that indicate the source of the metric (edgeR or DESeq2).
* :ref:`DNASeq <docs_gp_dnaseq>`
     - This release resolves an error that occurred in the `verifybamID`` step when using WES data by adding the proper exome BED file.
     - Fixes an Issue related to the path to custom `djerba`` formatting files.
     - Resolves unwanted restarts of PCGR step.
