GenPipes 6.2.0 Release Notes
============================

This is a medium release.

What's new?
-----------

This is a minor release of GenPipes:

* General
     - A GenPipes log report is now automatically created when running all the steps of a pipeline
     - MultiQC reports are now created with MultiQC version 1.35
* :ref:`LongRead DNASeq Pipeline <docs_gp_longread_dnaseq>`
    - Fixed a bug that prevented BAMs from being used as input files for the `nanopore` protocols
    - Added tools CHORD and PURPLE to the `nanopore_paired_somatic protocol` improved djerba cancer reports available with `nanopore_paired_somatic` protocol (requires OncoKB token)
* :ref:`MethylSeq <docs_methylation>`
    - Resolved unwanted restarts of call step in gembs protocol
* :ref:`RNASeq <docs_gp_rnaseq>`
     - PCGR reports in the cancer protocol now show gene fusions
     - PCGR version updated to 2.3.1
     - StarFusion version bumped to 1.15.1
* :ref:`DNASeq <docs_gp_dnaseq>`
     - Added new comprehensive protocol `somatic_ensemble_sv` that combines the `somatic_ensemble` and `somatic_sv protocols`
     - New tool CHORD added to the `somatic_ensemble_sv protocol`
     - Improved `djerba` cancer reports are available in the `somatic_ensemble_sv protocol` (requires OncoKB token)
     - Fixed a bug that passed the tumor's rather than the normal's genotype to CPSR for report generation
     - PCGR version updated to 2.3.1
     - Purple purity metrics are now displayed in PCGR report
     - Fixed a bug in the cnvkit_batch step that caused downstream plotting issues in the PCGR report
     - CNVkit version updated to 0.9.14
