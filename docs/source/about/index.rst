About
=====

GenPipes pipelines provide high-quality genomic analysis optimized for high-performance computing (HPC) and cloud environments. It is an open-source (`LGPL <https://github.com/c3g/GenPipes/blob/main/COPYING.LESSER>`_), Python-based platform for managing next-generation sequencing (NGS) workflows. 

GenPipes serves bioinformatics professionals, students, and researchers. It has been in use since 2013 and refined, refactored, tested, and widely adopted by researchers for :ref:`various genomic analyses<docs_available_pipelines>`.

The latest release is version \ |genpipes_version|\. 
See :ref:`Release Notes<docs_release_notes>` for details.
